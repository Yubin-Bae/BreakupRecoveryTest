# **전 애인에게서 DM이 온다면?**
## **프로젝트 개요**

**전 애인 DM 반응 테스트**

전 애인에게서 DM이 왔을 때의 선택을 통해 

사용자의 이별 극복 정도(감정 정리 수준)를 점수로 측정하는 심리 테스트입니다.

이 테스트는 단순한 반응 속도 측정이 아니라,

DM이 점점 감정 압박 -> 집착 -> 최종 선택으로 강화되는 흐름 속에서

사용자의 감정 개입 여부와 차단 일관성을 분석합니다.

## **테스트 구조**
- 총 15문항
- 모든 문항은 전 애인의 실제 DM 상황을 가정
- 각 문항마다 선택지는 2개
    - 감정 개입 / 관계 유지 신호
    - 무시 / 차단 / 감정 거리두기
 
- 문장 흐름:
  초기 감정 탐색 -> 심리 흔들기 -> 압박 -> 집착 -> 최종 반응

## 점수 체계
- 각 문항 선택지 점수: 0점 또는 1점
- 총점 범위: 0–15점
- 점수가 높을수록 감정 차단 및 이별 정리 수준이 높음

## 해석 기준
- 0–6점 | 이별 미극복 구간
  - 감정 개입 빈번
  - 반응 속도 빠름
  - 관계 재진입 가능성 높음

- 7–9점 | 경계 구간
  - 행동은 차단하지만 감정은 잔존
  - 이별은 했지만 정서적으로 완결되지 않은 상태

- 10–15점 | 이별 극복 구간
  - 감정과 행동이 일치
  - 전 애인의 DM에도 일상 유지 가능
  - 이별을 하나의 ‘결정’으로 처리한 상태

**※ 이별 극복 최소 기준선: 10점 이상**

## 구현 방식 (로직 요약)
- Google Sheet에는 다음 정보만 저장
  - 질문 텍스트
  - 선택지 텍스트
  - 선택지별 점수 (0 / 1)

- 코딩 단계에서:
  - 사용자가 선택한 선택지의 점수만 읽음
  - 점수 합산
  - 총점에 따라 결과 문구 출력
